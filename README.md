Hello!

Here is a cool project that I've been working on. It's a small jukebox/music player that can play up to 9 songs! Here are the CAD, CODE and diagram files. 

This project uses the esp8266 development board that was designed by espressif.

Repository contents:
1) Onshape CAD files for 3D printing.
2) Code- coded using Arduino IDE.
3) Diagrams of the entire setup.
4) Product and resources that can be found online.

Side Note: 
- The 3D printing files are in STL format. There are 2 files. Both parts fit into each other making the project complete.

Happy tinkering!
